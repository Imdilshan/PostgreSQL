# PostgreSQL

Learning PostgreSQL through hands-on practice, SQL challenges, and real-world case studies.

This repository contains my solutions, queries, and notes from the **SQL Practice Queries** course on CodeChef.

## Course

**[SQL Practice Queries – CodeChef](https://www.codechef.com/practice/sql-case-studies-topic-wise)**

The course covers SQL fundamentals and gradually moves towards intermediate-level querying through practical exercises and case studies.

## Topics Covered

- Basic SQL Commands
- Filtering and Sorting
- Aggregate Functions
- GROUP BY and HAVING
- Joins
- Subqueries
- CASE Expressions
- Real-world SQL Case Studies
